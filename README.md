This make.fun entry is a short poem about a cooling loaf. Its quiet kitchen scene reaches back to the field where the wheat grew.

## How it works

Run `node main.ts` with Node.js 22. The program writes the same UTF-8 text to `/output/entry.txt` on every run. Set `MAKEFUN_OUTPUT_DIR` to choose another directory.
